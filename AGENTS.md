# AGENTS.md - AI Agent Instructions

This document provides instructions for AI coding agents working in this repository.

## Project Overview

**Name:** runner-fallback-action (Runner Selector)
**Type:** GitHub Action (Node.js)
**Language:** JavaScript (CommonJS)
**Runtime:** Node 20

A GitHub Action that dynamically selects runners for workflow jobs. It checks
primary self-hosted runner availability via the GitHub API and falls back to
GitHub-hosted runners if they are offline.


## Code Style Guidelines

### Imports

- Use **CommonJS syntax** (`require()` / `module.exports`)
- Standard library imports first, then third-party packages
- No TypeScript - pure JavaScript

```javascript
const core = require("@actions/core");
const httpClient = require("@actions/http-client");
```

### Formatting

- **Indentation:** Tabs
- **Quotes:** Double quotes for strings
- **Semicolons:** Always use semicolons
- **Trailing commas:** Yes, in multi-line objects/arrays
- **Line length:** Keep reasonable, no strict limit

### Naming Conventions

| Element       | Convention  | Example                           |
|---------------|-------------|-----------------------------------|
| Variables     | camelCase   | `useRunner`, `primaryIsOnline`    |
| Functions     | camelCase   | `checkRunner`, `main`             |
| Constants     | camelCase   | `checkOrgRunners` (no UPPER_CASE) |
| Parameters    | camelCase   | `githubToken`, `primaryRunner`    |
| Test names    | Descriptive | "should use the primary runner"   |

```javascript

        core.setFailed(error);

    core.setFailed(error.message);
```


## Testing Patterns

### Framework & Tools

- **Framework:** Jest
- **Mocking:** `jest.mock()` for external dependencies
- **Structure:** `describe` blocks with `it` statements

### Test File Structure

```javascript
const mockGetJson = jest.fn();

jest.mock("@actions/http-client", () => {
    return {
        HttpClient: jest.fn().mockImplementation(() => {
            return { getJson: mockGetJson };
        }),
    };
});

describe("checkRunner", () => {
    it("should use the primary runner if it is online", async () => {
        mockGetJson.mockResolvedValue({ /* ... */ });
        const result = await checkRunner({ /* ... */ });
        expect(result).toEqual({ /* ... */ });
    });
});
```

### Test Naming

- Start with "should" for clarity
- Be descriptive about the expected behavior
- Example: "should fall back when primary runner is offline"

## GitHub Action Configuration

**Inputs (action.yml):**
- `primary-runner` (required): Comma-separated labels for primary runner
- `fallback-runner` (required): Label for fallback runner
- `github-token` (required): Token with `actions:read` permission
- `check-org-runners` (optional): Boolean to check org-level runners

**Outputs:**
- `use-runner`: JSON-formatted string of runner labels for `fromJson()`
